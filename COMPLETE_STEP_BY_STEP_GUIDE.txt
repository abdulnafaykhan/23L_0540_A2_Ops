    Conv2D (32, 64, 128 filters), BatchNormalization, MaxPooling2D, Dropout(0.4),
    and Dense(1, sigmoid) with parameter count.

WHY WE CHOSE THESE LAYERS:
  - Conv2D + Relu: Extract hierarchical visual feature maps (edges -> textures -> shapes).
  - BatchNormalization: Normalizes activations between layers, speeding up convergence.
  - MaxPooling2D: Downsamples spatial dimensions (2x2), reducing parameters and compute.
  - Dropout(0.4): Randomly zeroes 40% of hidden neurons during training to prevent co-adaptation.
  - Sigmoid Output: Compresses output into a probability [0.0, 1.0] for binary classification.
  - Loss: Binary Cross-Entropy (standard for Bernoulli probability distribution).
  - Optimizer: Adam (adaptive learning rate for sparse gradients).

--------------------------------------------------------------------------------
WHAT TO INCLUDE IN REPORT (Evidence 2.3):
  - Embed `task2_transfer_learning_curves.png`.
  - Explanation:
    - Pretrained Backbone: MobileNetV2 pretrained on 1.4 million ImageNet images.
    - Stage 1 (Frozen): MobileNetV2 base weights frozen; custom Dense head trained for
      5 epochs with Adam (lr=1e-3). This protects pretrained weights from destructive gradients.
    - Stage 2 (Fine-Tuning): Top 25 layers unfrozen; trained for 5 epochs with a smaller
      learning rate (lr=1e-5) to adapt high-level feature representations to AI artifact detection.
    - Preprocessing: Standard MobileNetV2 scaling to [-1, 1] using (x / 127.5) - 1.

SUB-TASK 6.2: DOCKERFILE FOR WEB APP (3 MARKS)
--------------------------------------------------------------------------------
WHAT TO DO:
  Create `Dockerfile` adhering to production best practices:
    - Base: `python:3.11-slim` (minimal size, avoids heavy build tools).
    - Cache Layer Order: `COPY requirements.txt .` followed by `RUN pip install --no-cache-dir -r requirements.txt` BEFORE `COPY . .`.
      (Why: Code changes frequently, but dependencies rarely change. Placing dependencies first allows Docker to reuse the cached layer).
    - Non-root user: `USER appuser` to avoid running container processes as root.
    - Healthcheck: `HEALTHCHECK CMD curl -f http://localhost:5000/health || exit 1`.
    - `.dockerignore`: Exclude `.venv`, `__pycache__`, `.git`, `.env`.

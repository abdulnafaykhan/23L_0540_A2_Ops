## 🛡️ Overview
VisionGuard is a robust, end-to-end MLOps solution that classifies whether an uploaded image was generated by synthetic AI or captured photographically.

The system features:
- **Data Versioning**: DVC tracking with SHA-256 cryptographic hashing to eliminate exact bitwise duplicates.
- **Deep Learning Backbone**: Pretrained MobileNetV2 fine-tuned with two-stage training discipline.
- **Experiment Tracking**: MLflow tracking and Model Registry hosted on DagsHub with `@champion` alias versioning.
- **Web Serving**: Production Flask web application with strict in-memory MIME validation and audit trail logging.
- **Containerization**: Isolated multi-service Docker Compose stack (Web application + internal PostgreSQL database).
- **CI/CD Automation**: GitHub Actions workflow testing Python 3.10/3.11 matrix and Docker image builds on every push.
